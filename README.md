# Сайт ТЕХ-ЭНЕРГО (teh-enerdgy.ru)

Статический сайт: ударные клейма (каталог с Ozon), гидравлические прессы, конструктор клейма, заявки.
Сборка — Node.js без зависимостей, на выходе папка `dist/` (обычный HTML + `send.php` для формы).

Текущее состояние, решения и что ждём от клиента — в [HANDOFF.md](HANDOFF.md).



| Файл | Что это |
|---|---|
| `data/company.json` | Все факты о компании: телефон, почта, адрес, реквизиты, ссылки, рейтинг Ozon. Меняем только здесь. |
| `data/ozon_raw.json` | Сырая выгрузка магазина Ozon (65 товаров, 12.10.2026). |
| `data/products.json` | Каталог сайта — **генерируется** из `ozon_raw.json`, руками не править. |
| `data/laser.json` | Страница «Лазерная гравировка»: вводный текст, цифры, услуги и цены (источник — старый сайт и ВК). У каждой услуги — адрес своей страницы `/gravirovka/<slug>/`. |
| `data/matrix.json` | Страница «Матрицы и пуансоны»: тексты и фото работ (`public/img/matrix/`), у каждой работы — адрес страницы `/matricy/<slug>/`. |
| `data/press.json` | Пресс П-50-AVR-200: характеристики, режимы, опции (источник — Ozon и пост в ВК). |
| `scripts/import-ozon.js` | `ozon_raw.json` → `products.json`. Ручные правки названий, категорий и характеристик с фото — в `OVERRIDES` и `PHOTO_SPECS` внутри. |
| `scripts/download-images.js` | Докачивает фото товаров с CDN Ozon в `public/img/products/<артикул>/` (`N.webp` — 1000 px, `N-s.webp` — 400 px). |
| `scripts/build.js` | Шаблоны всех страниц и сборка в `dist/`. |
| `src/css/style.css`, `src/js/main.js` | Стили и скрипты (меню, фильтры каталога, галерея, конструктор, формы, cookie). |
| `src/send.php` | Обработчик заявок: письмо на почту. |

## Команды

```bash
node scripts/import-ozon.js   # пересобрать каталог из выгрузки
node scripts/build.js         # собрать сайт в dist/
php -S 127.0.0.1:8090 -t dist # посмотреть локально (http://127.0.0.1:8090)
```

## Обновление каталога с Ozon

Ozon закрыт антиботом, поэтому выгрузка делается через настоящий Chrome (Playwright), запросом
`/api/entrypoint-api.bx/page/json/v2?url=/seller/teh-enerdgy-2374593/?page=N` со страницы магазина.
Если делать много запросов подряд, Ozon на время начинает отдавать страницу антибота — делайте паузы.
Новые товары: дописать в `ozon_raw.json` → `download-images.js` → `import-ozon.js` → `build.js`.
Даты цен на сайте не показываются (решение пользователя 14.10.2026).

## Выкладка

Нужен хостинг с PHP 7.4+ и Apache (Beget, Timeweb, reg.ru…): залить **содержимое** `dist/` (включая `.htaccess`) в корень сайта.
`.htaccess` включает HTTPS, страницу 404, склейку `www` → без `www` и 301-редиректы со всех адресов старого сайта на Tilda (см. ниже).
Сейчас домен работает на Tilda — при переносе нужно переключить DNS домена на новый хостинг.

**Yandex Object Storage не подходит без доработки:** там не выполняется `send.php` и не читается `.htaccess` —
форма заявки работать не будет, пока не сделать приём заявок через Cloud Function.

Перед запуском:
1. Почта получателя и домен подставляются в `send.php` из `data/company.json` при сборке.
2. Отправить тестовую заявку с файлом и убедиться, что письмо пришло на teh-enerdgy@mail.ru (и не в спам). Ящик `no-reply@teh-enerdgy.ru` лучше завести на хостинге.
3. Яндекс Вебмастер — см. «Перенос со старого сайта».

## Перенос со старого сайта (Tilda) без потери позиций

Домен тот же, поэтому «переезд сайта» в Вебмастере **не нужен**: главное зеркало остаётся `https://teh-enerdgy.ru` (без www, как было).
Вес старых страниц передают 301-редиректы в `public/.htaccess`, каждый сразу на конечный https-адрес, без цепочек:

- страницы: `/politic` → `/politika/`, `/sogl` → `/soglasie/`, `/catalog` → `/catalog/`, `/thanks` и служебные страницы Tilda → главная, `/sitemap-store.xml` → `/sitemap.xml`;
- 29 товаров магазина Tilda (`/catalog/tproduct/<id>-…`, список из старого `sitemap-store.xml` на 15.10.2026) — по id на ту же позицию в новом каталоге, на страницу услуги гравировки или на `/matricy/`; товары без аналога (АС, НАКС, клеймо для заклёпок) — в каталог, снятое оборудование (сопла, термопресс, лазеры) — на главную;
- `www.` и `/index.html` → основной адрес.

`node scripts/build.js` падает с ошибкой, если редирект ведёт на страницу, которой нет в `dist/`. Если меняется адрес страницы (slug клейма или услуги), поправить и `.htaccess`.

Чек-лист в день переноса:
1. **До переключения DNS** выгрузить из Вебмастера старого сайта «Индексирование → Страницы в поиске» и проверить, что для каждого адреса есть правило в `.htaccess`. Если в поиске есть адрес, которого нет в этом списке, дописать правило.
2. Переключить DNS, выпустить SSL-сертификат на хостинге (для `teh-enerdgy.ru` и `www`).
3. Проверить редиректы: `curl -sI https://teh-enerdgy.ru/catalog/tproduct/579072598632-kleimo-otk5-10-100` — `301` и `Location` на новую страницу; так же `http://`, `www.`, `/politic`.
4. Вебмастер: «Индексирование → Файлы Sitemap» — удалить `sitemap-store.xml`, добавить `https://teh-enerdgy.ru/sitemap.xml`; «Переобход страниц» — главная, `/catalog/`, `/pressy/`, `/matricy/`, `/gravirovka/` и самые посещаемые старые адреса.
5. Если права в Вебмастере подтверждены мета-тегом или файлом Tilda — перенести их (тег — в `layout` в `build.js`, файл — в `public/`), иначе права слетят. В HTML старого сайта мета-тега нет (проверено 15.10.2026), значит, если сайт добавлен, то через DNS или файл.
6. Яндекс Бизнес (карточка организации) — ссылка на сайт не меняется, проверить телефон и адрес.
7. Две–четыре недели смотреть в Вебмастере «Индексирование → Статистика обхода»: ошибки 404 и «Страницы в поиске → Исключённые».
8. Редиректы не удалять минимум год.
