# Сайт ТЕХ-ЭНЕРГО (teh-enerdgy.ru)

Статический сайт: ударные клейма (каталог с Ozon), гидравлические прессы, конструктор клейма, заявки.
Сборка — Node.js без зависимостей, на выходе папка `dist/` (обычный HTML + `send.php` для формы).

Текущее состояние, решения и что ждём от клиента — в [HANDOFF.md](HANDOFF.md).



| Файл | Что это |
|---|---|
| `data/company.json` | Все факты о компании: телефон, почта, адрес, реквизиты, ссылки, рейтинг Ozon. Меняем только здесь. |
| `data/ozon_raw.json` | Сырая выгрузка магазина Ozon (65 товаров, 12.10.2026). |
| `data/products.json` | Каталог сайта — **генерируется** из `ozon_raw.json`, руками не править. |
| `data/press.json` | Пресс П-50-AVR-200: характеристики, режимы, опции (источник — Ozon и пост в ВК). |
| `scripts/import-ozon.js` | `ozon_raw.json` → `products.json`. Ручные правки названий, категорий и характеристик с фото — в `OVERRIDES` и `PHOTO_SPECS` внутри. |
| `scripts/download-images.js` | Докачивает фото товаров с CDN Ozon в `public/img/products/<артикул>/` (`N.webp` — 1000 px, `N-s.webp` — 400 px). |
| `scripts/build.js` | Шаблоны всех страниц и сборка в `dist/`. |
| `src/css/style.css`, `src/js/main.js` | Стили и скрипты (меню, фильтры каталога, галерея, конструктор, формы, cookie). |
| `src/send.php` | Обработчик заявок: письмо на почту + по желанию Telegram. |

## Команды

```bash
node scripts/import-ozon.js   # пересобрать каталог из выгрузки
node scripts/build.js         # собрать сайт в dist/
php -S 127.0.0.1:8090 -t dist # посмотреть локально (http://127.0.0.1:8090)
```

## Обновление каталога с Ozon

Ozon закрыт антиботом, поэтому выгрузка делается через настоящий Chrome (Playwright), запросом
`/api/entrypoint-api.bx/page/json/v2?url=/seller/teh-enerdgy-2374593/?page=N` со страницы магазина.
Если делать много запросов подряд, Ozon на время начинает отдавать страницу антибота — делайте паузы.
Новые товары: дописать в `ozon_raw.json` → `download-images.js` → `import-ozon.js` → `build.js`.
Цены на сайте подписаны «цена на Ozon на <дата>» — дата берётся из `products.json` (`updated`).

## Выкладка

Нужен хостинг с PHP 7.4+ и Apache (Beget, Timeweb, reg.ru…): залить **содержимое** `dist/` (включая `.htaccess`) в корень сайта.
`.htaccess` включает HTTPS, страницу 404 и 301-редиректы со старых адресов Tilda (`/politic`, `/sogl`, `/catalog`).
Сейчас домен работает на Tilda — при переносе нужно переключить DNS домена на новый хостинг.

**Yandex Object Storage не подходит без доработки:** там не выполняется `send.php` и не читается `.htaccess` —
форма заявки работать не будет, пока не сделать приём заявок через Cloud Function.

Перед запуском:
1. Почта получателя и домен подставляются в `send.php` из `data/company.json` при сборке. При желании вписать `TG_TOKEN` / `TG_CHAT` в `src/send.php` и пересобрать.
2. Отправить тестовую заявку с файлом и убедиться, что письмо пришло на teh-enerdgy@mail.ru (и не в спам). Ящик `no-reply@teh-enerdgy.ru` лучше завести на хостинге.
3. Добавить сайт в Яндекс Вебмастер и отправить `sitemap.xml`.
